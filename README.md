# SiteHub

**Self-hosted панель ссылок на ваши сайты и сервисы**: плитки с иконками, группы, поиск, мониторинг доступности. В комплекте простая админка, пользователи с ролями, двухфакторная аутентификация и защита от подбора паролей. HTTPS настраивается из веб-интерфейса.

Интерфейс на русском и английском. Работает без интернета и внешних CDN — удобно ставить в локальной сети.

## Возможности

**Главная страница**
- Плитки сайтов с автоматически загружаемыми favicon. Вместо иконки можно поставить эмодзи или загрузить свою картинку; у каждого сайта может быть свой цвет акцента.
- Группы, мгновенный поиск (`/` — фокус, `↑↓` — выбор, `Enter` — открыть), режимы «плитки» и «список».
- Статус «онлайн / недоступен» с временем отклика и аптаймом за 24 часа. Статусы обновляются на странице сами, без перезагрузки.
- Светлая, тёмная и автоматическая тема, часы с приветствием, адаптивная вёрстка для телефона, установка как PWA.
- Закрытые сайты видны только после входа. Главную можно сделать полностью приватной.

**Админ-панель**
- Сайты и группы: добавление и редактирование. Порядок меняется перетаскиванием, так же сайт переносится между группами.
- История проверок сайта, аптайм за 24 часа и 7 дней, счётчик переходов.
- Пользователи с ролями `admin` (всё), `editor` (сайты и группы) и `viewer` (просмотр, включая закрытые сайты). Пароли можно генерировать, учётки — блокировать.
- Импорт и экспорт всех сайтов в JSON.

**Безопасность**
- Пароли хранятся в виде хешей Argon2id.
- Защита от перебора: IP блокируется после N ошибок за окно времени. Отдельно временно блокируется учётная запись при распределённом переборе. Есть белый список IP/подсетей и ручное снятие блокировок.
- 2FA (TOTP) с QR-кодом подходит для Google Authenticator, Яндекс Ключа, Aegis и 2FAS. Есть 8 одноразовых резервных кодов и защита от повторного использования кода. 2FA можно сделать обязательной для администраторов.
- CSRF-токены, подписанные cookie сеанса (HttpOnly, SameSite, Secure при HTTPS) и строгий Content-Security-Policy.
- При смене пароля завершаются остальные сеансы; есть кнопка «завершить другие сеансы».
- Журнал событий: входы, баны, изменения настроек, падения и восстановления сайтов.
- Сервис работает от непривилегированного пользователя `sitehub`, в systemd-песочнице.

**Сервер и SSL** (всё настраивается из веб-интерфейса)
- Смена порта и адреса прослушивания; сервис перезапускается сам.
- Режимы HTTPS:
  - **Let's Encrypt** — получение в один клик, автопродление;
  - **свой сертификат** — загрузка файлов или вставка PEM;
  - **самоподписанный** — для локальной сети.
- Редирект HTTP:80 → HTTPS.
- Защита от «потери» доступа: если сертификат не загрузился, сервис стартует по HTTP. Порт и SSL можно сбросить из консоли.

## Установка

Debian 12/13 или Ubuntu 22.04+ (подходит LXC-контейнер), от root:

```bash
curl -fsSL https://raw.githubusercontent.com/AlexsandrPetrov/sitehub/main/install.sh | bash
```

Установщик:
1. ставит зависимости;
2. разворачивает приложение в `/opt/sitehub`, данные — в `/var/lib/sitehub`;
3. создаёт systemd-сервис `sitehub`;
4. выводит адрес и пароль администратора.

По умолчанию сервис слушает порт `8080`. Начальный порт можно задать так: `PORT=80 bash install.sh`.

**Обновление** — тот же установщик ещё раз: он подтянет новую версию из Git, данные сохранятся.

## Консольные команды

```
sitehub users                     список пользователей
sitehub create-admin <login>      создать администратора (пароль сгенерируется)
sitehub passwd <login> [пароль]   сбросить пароль
sitehub disable-2fa <login>       отключить 2FA (если потерян телефон)
sitehub unban [ip|--all]          снять блокировки
sitehub set-port 8080             сменить порт
sitehub ssl-off                   вернуться на HTTP
sitehub show                      текущие настройки
```

После `set-port` и `ssl-off` выполните `systemctl restart sitehub`.

## Let's Encrypt

1. Направьте DNS-запись домена на сервер. Порт 80 должен быть доступен из интернета.
2. В разделе «Сервер и SSL» нажмите «Получить сертификат».
3. Выберите режим «Let's Encrypt», укажите порт (обычно 443) и нажмите «Применить».

Сертификат продлевается автоматически, за 30 дней до истечения. Пока включён редирект, проверки на порту 80 обслуживает сам SiteHub.

## Разработка

```bash
python3 -m venv venv && . venv/bin/activate
pip install -r requirements.txt
SITEHUB_DATA=./data python -m sitehub.cli create-admin admin
SITEHUB_DATA=./data python -m sitehub.run      # http://localhost:8080
```

Стек: Python 3.11+, FastAPI, Jinja2 и SQLite. Фронтенд — чистые CSS и JS, без сборки.

### English

SiteHub is a self-hosted start page / link dashboard for your sites and services. Features:
- uptime monitoring and favicon tiles with groups and search;
- an admin panel with role-based users;
- TOTP 2FA with QR codes and recovery codes, plus brute-force protection;
- port changes and HTTPS (Let's Encrypt, your own certificate or self-signed) managed from the web UI.

Install with `curl -fsSL https://raw.githubusercontent.com/AlexsandrPetrov/sitehub/main/install.sh | bash`. The UI is in Russian and English.
